# References and Inspirations

- [CTFd](https://github.com/CTFd/CTFd) inspired the high-level challenge discovery, answer submission, and administration workflow. CyberLab Hub is an original Go implementation and is not a fork; no CTFd source code is included.
- [Gin documentation](https://gin-gonic.com/en/docs/) for HTTP routing and middleware concepts.
- [gRPC Go documentation](https://grpc.io/docs/languages/go/) and [Protocol Buffers](https://protobuf.dev/) for the typed catalog contract.
- [tview](https://github.com/rivo/tview) for the terminal UI framework.
- [Gorilla WebSocket](https://github.com/gorilla/websocket) for WebSocket transport.

Generated protobuf files are produced from this repository's own `.proto` source. Third-party Go dependency versions and checksums are recorded in `go.mod` and `go.sum`.
